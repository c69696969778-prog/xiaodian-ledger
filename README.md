# 小店账本 · 完整源码

这是已发布展示网站的完整前端源码，所有界面、样式、示例数据、业务逻辑及 Excel 导出代码都包含在 `index.html` 中。无需安装前端依赖，没有省略的编译产物或后端服务。

## 运行

最简单的方法：直接双击 `index.html`，用浏览器打开。

也可以安装 Python 3 后，在本目录运行：

```sh
python serve.py
```

然后访问 http://127.0.0.1:8000 。按 Ctrl+C 停止。

## 文件

- `index.html`：完整应用，包含 HTML、CSS、JavaScript、示例数据、SVG 图表和 XLSX 导出。
- `serve.py`：可选的本机静态服务器，仅用于本地查看。
- `改版说明与参考来源.md`：功能说明、数据口径、参考产品和验证边界。

## 功能

经营总览、日期与支出口径筛选、收支流水、快速记账、编辑与撤销、签字单应收、账龄和客户明细、员工考勤、经营报告、Excel 导出、JSON 备份与恢复。

## 数据保存

当前没有数据库、用户登录或后台 API。数据保存在每位访客当前浏览器的 localStorage 中，不跨设备同步。首次打开使用2026年10月示例数据。重新部署或更换网址不会自动迁移旧网址下的本地记录，请使用导出/导入备份迁移。

## 部署

这是普通静态网站。将 `index.html` 上传到支持静态 HTML 的网站托管空间即可，首页文件名保持为 `index.html`。不需要 npm install，也不需要构建命令。是否允许匿名访问、使用什么域名，由所选托管平台配置。

本源码包不包含原托管平台的账户绑定配置或凭据，可用于其他托管平台。
